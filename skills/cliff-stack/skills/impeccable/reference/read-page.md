# Reading page

Load this reference when the surface is a reading page: a guide, documentation, an article, a changelog. It complements the register reference ([brand.md](brand.md) or [product.md](product.md)) and never replaces it. On a reading page the visitor came to understand something, so the page is first a document of its kind, framed by the brand's world.

## Direction

The reader's question leads. Comprehension and wayfinding stay intact at every step. Documentation reads as documentation, a guide as a guide, an article as an article, a changelog as a changelog.

The world owns the frame and serves the column:

- **The frame** is the masthead, the navigation rail, the ground, the title and section openers, and the way code, tables, and callouts are set. There the palette, type, and signature move commit fully, so the page could belong to no other product.
- **The reading column** inside it stays calm: a reading face, real contrast, a real measure, nothing performing behind the text.
- The world never supplies the reading order, and never replaces the navigation with something a reader has to learn.

The world's own publishing traditions transfer best: reference books, type specimens, timetables, field guides, technical manuals, scholarly apparatus, a newspaper's wayfinding. A tool, instrument, or fictional interface from the audience's world turns into a costume on a page meant for reading: take from it only what transfers as type, palette, density, and a signature move.

## First viewport: the document's shell

Write each direction's first viewport as the document's shell before anything else:

1. The navigation, and where the reader stands in it.
2. The title, and the opening that answers or frames the reader's question.
3. The reading column.
4. The way forward: contents, section headings, previous and next.

Then name where the world owns the frame and where the signature move lives: a masthead, a coloured rail, a running head, a margin system, a numbering scheme, a way of setting code or tables. Keep one signature move, a single system used where it earns its place, never a frame repeated around every element.

## Reading column

- Measure about 60 to 75 characters per line, body text near 16px.
- Body in a reading face with real contrast against its ground. Monospace is for code, parameters, and small labels, never the running text or the headings by default.
- Headings in a clear hierarchy a reader can scan.
- Code, tables, notes, and figures sit in the standard forms readers already know, set in the world's type and palette.
- The page never reads as a poster, a magazine cover, or a book photographed open.

Type and spacing mechanics live in [typeset.md](typeset.md) and [layout.md](layout.md).

## Direction probes

When [shape.md](shape.md) Phase 1.5 calls for visual direction probes, draw them in a Claude Design canvas, one artboard per probe. Each probe is the document as the reader meets it: the frame in the direction's committed palette and type, around a calm reading column at a real measure, with the wayfinding that carries the reader through.

- Fill each probe with the real material: the actual title, a real opening paragraph, real section names, and one example of the hardest content the surface holds. Never filler text.
- Probes vary the reading structure and how the frame carries the world, never the column: the navigation model (sidebar tree, top tabs, inline contents), the column and margin system, how densely the reference material sits, where the signature move appears.
- Each probe is recognisably different from the others at thumbnail size.
- A variant that pushes world material into the reading column goes the wrong way.

## Self-check

Run it on every probe and every build:

1. Can a reader tell where they are and where to go next, and read the body comfortably?
2. Cover the name: could this page belong to another brand? If so, the frame has not committed.
3. Does the render read as an artifact of the world before it reads as a document? Then the world has reached the column: pull it back to the frame.
