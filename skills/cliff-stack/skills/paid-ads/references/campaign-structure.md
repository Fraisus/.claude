# Canaux & structure de campagnes — détail

## Canaux (solo / petit budget)
| Canal | Type | Pour qui | Note |
|---|---|---|---|
| **Google Search** | intention | tous | Le défaut. Plus haut CVR, feedback rapide. |
| **Microsoft/Bing** | intention | B2B/devs/IT | CPC 30-50 % moins cher, audience desktop/pro. Activer tôt. Cible aussi le pro via données LinkedIn (CPA ~31 % < LinkedIn direct). |
| **Reddit** | semi-intention | dev tools, infra | CPC ~1,50-3 $. Catégorie-dépendant ; vidéo. La plupart des SaaS B2B génériques ne devraient pas y être. |
| **Meta** | interruption | prosumer/grand public | Retargeting + démo. Faible en froid B2B niche. |
| **LinkedIn** | interruption ciblée | B2B haut ACV | CPC 5-12 $+, plancher test ~4-5 k$/mois. Souvent hors budget modeste. |
| **YouTube** | notoriété | retargeting/démo | Pas un 1er canal petit budget. |

> Règle : intention d'abord (Search Google + Bing), interruption (Meta) en retargeting / après validation. **2 canaux max** sous ~15 k$/mois.

## Structure Google Ads
- **Petit budget = Search classique seul.** PMax inadapté (Display avale le budget, cannibalise la marque) → seulement après 60+ conv/mois + CRM.
- **AI Max for Search** : couche IA sur Search classique (search term matching, text customization, URL expansion) AVEC garde-fous (brand controls, URL controls, locations of interest). Sans minimum de dépense. ~+14 % conv. Vérifier les modèles de suivi (risque 404 sur URL dynamiques). Le compromis recommandé vs PMax.
- **Ad groups thématiques** (SKAG mort) : clusters d'intention
  - outcome / résultat
  - comparaison / « alternative à X »
  - pain point
  - marque-concurrent
  - **campagne marque dédiée** (isolée, négatifs partagés pour éviter la cannibalisation).

## Match types
- **Phrase = défaut de démarrage** (petit budget).
- **Exact** pour les mots-clés à forte intention/valeur (marque, « alternative à X », « prix/acheter »).
- **Broad seulement APRÈS** historique de conversions + liste de négatifs rigoureuse + Smart Bidding alimenté. Sinon = budget cramé sur requêtes hors-sujet.
- **Négatifs** : liste partagée, mise à jour continue (« free », « jobs », « DIY », « tutorial », « download crack »…).

## Meta
- **Advantage+** cible l'algo (on guide par signaux + créa). **Advantage+ Sales/Shopping = e-commerce produit only** → un SaaS/service utilise des **campagnes standard**.
- ~50 $/jour min pour sortir de la learning phase (50 conv/7 j).
